# Crimson Channels color palettes

The theme ships its light and dark color palettes through `about.json` as theme-owned Discourse color schemes.

For an existing remote installation, use **Admin > Appearance > Themes and components > Crimson Channels > Check for updates / Update** after pulling a release that changes palette metadata. Discourse imports and updates theme-owned color schemes during the remote-theme update step.

After updating, the palettes are available under the theme's light/dark color palette selectors and in the administrator color palette list.
